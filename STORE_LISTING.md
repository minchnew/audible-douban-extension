# Audible + Douban

See Douban book ratings and popular short comments alongside Audible book details.

## Short description

Adds a Douban book information panel to Audible book pages.

## Full description

Audible + Douban helps you look up a book on Douban while browsing its Audible product page. It reads the Audible book title, searches Douban Books, and displays the best matching book's rating, author, and up to five popular short comments in a movable panel. Open the Douban entry directly from the panel, or use the search link if Douban asks you to complete a verification check.

The extension runs on Audible `/pd/…` book detail pages. To perform a lookup, it sends the book title to Douban and requests the matching Douban book and comments pages. Those requests use your browser's existing Douban cookies when applicable. The extension does not read or store cookie values, and it does not save lookup data or send it to an extension developer server.

## Permissions

- **Audible book pages:** Reads the displayed book title and adds the information panel.
- **Douban book search and detail pages:** Searches for the title and retrieves the matching book information and short comments.
